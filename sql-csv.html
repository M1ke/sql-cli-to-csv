CSV Tools

Made by M1ke - Find this on GitHub

Extract, sort and wrap columns from CSV/TSV data, or convert SQL CLI table output into CSV.

This is filled in from the SQL CLI box above, but you can also paste CSV or TSV data straight in here and the features below will still work.

Enter the name of a column, e.g "email" and if your CSV contains that column, the below textarea will include all values comma-separated.

With either of the above ticked and no column name, the first column is used.

Wrapping lets you replace a value in a string with the value of the named column above, using the placeholder %% (two percent signs). To see how this works try out "Hello %% world %%"

All processing for this is done in your browser; no data is sent to any remote server

Example

If you're unsure what the SQL CLI box is expecting, try pasting in the following:

+---------+--------------+
| user_id | name         |
+---------+--------------+
|       1 | Tim Fish     |
|       9 | Steve Mullet |
|      23 | Ken Salmon   |
+---------+--------------+
