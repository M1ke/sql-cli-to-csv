Example Usage:

Enter a domain name (e.g., google.com) and select a record type to query. The tool uses Google's DNS-over-HTTPS API to fetch DNS records.

  • A - Maps a domain to an IPv4 address. The most common DNS record type.
  • AAAA - Maps a domain to an IPv6 address.
  • MX - Specifies the mail server for the domain, with a priority value (lower = higher priority).
  • TXT - Stores arbitrary text; used for SPF, DKIM, domain ownership verification, and more.
  • NS - Identifies the authoritative name servers for the domain.
  • CNAME - Creates an alias pointing to another domain name (canonical name).
  • SOA - Holds zone administration data: primary name server, contact address, and serial number.
  • PTR - Reverse DNS lookup; maps an IP address back to a domain name.
  • CAA - Restricts which Certificate Authorities may issue SSL/TLS certificates for the domain.
  • SRV - Specifies the host and port for a specific service (e.g., SIP, XMPP).

All processing for this is done in your browser; no data is sent to any remote server (except the DNS-over-HTTPS query to Google's public DNS API)
