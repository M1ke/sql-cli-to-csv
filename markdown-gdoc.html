Markdown to Google Doc

Convert markdown to formatted content that can be pasted directly into Google Docs

How to use:
  1. Paste your markdown in the textarea below
  2. Preview the formatted output on the right
  3. Click "Copy Formatted Content"
  4. Paste into Google Docs - formatting will be preserved!
