Web Tools

A collection of browser-based developer utilities

AI CSV Transformer

Transform CSV data using AI-generated JavaScript functions without uploading your data to any LLM service.

JWT Parser and Editor

Decode JWT tokens, edit header and payload sections, and reconstruct tokens with modified values.

JSON Editor

Format, lint, and validate JSON with optional JSON Schema validation. Save and load named documents to browser local storage.

DNS Lookup Tool

Query DNS records for any domain using DNS-over-HTTPS. Supports A, AAAA, MX, TXT, NS, CNAME, and more.

Markdown to Google Doc

Convert markdown to formatted content that can be pasted directly into Google Docs with preserved formatting.

Word Count Tool

Count words in text with support for ignoring content within square brackets and treating numbers as words.

CSS Colour Extractor

Paste any text containing CSS colour values and get a visual list of all colours found, with swatches. Supports hex, rgb/rgba, and hsl/hsla.

Psalm Array Type Comparator

Compare two Psalm array type definitions from error messages and identify the differences between them.

SQL CLI to CSV Converter

Convert SQL command-line table output into CSV (or TSV) format, extract specific columns, and wrap values with custom templates.

SQL Insert Generator

Transform SQL SELECT output into INSERT statements for easy data duplication.

Tech Debt Generator

Generate random JavaScript code filled with anti-patterns and bad practices. Perfect for code review training and refactoring demos.

Eurovision Bingo

A randomised bingo card of things that happen during the Eurovision Song Contest. Tap each square as you spot them while watching the show.

For additional encoding and decoding tools, check out Cryptii.
